Lossless Office document engines in Rust

DOCX round-trips byte-for-byte on untouched parts. Line breaking is Knuth–Plass optimal with UAX#14 rules. The same core compiles to native and wasm — the browser is not a second implementation.

Try the playground Read the roadmap

Why lossless#

Office files die quietly in tools that don't understand parts of them. Quire treats every OPC entry as a claim: parse what you can model, re-emit everything else exactly as received. The CI gate proves it — 399 real-world files, byte-identical, every push, two OSes.

The pipeline#

  1. Parse — OPC unzipped entry by entry; unknown parts claimed, never dropped.
  2. Shape — shaped advances against real fonts: kerning, CJK widths, fallback chains.
  3. Break — Knuth–Plass minimises total badness per paragraph; UAX#14 guards legality.
  4. Paginate — paragraph caches reflow only the dirty interval; background break passes.
  5. Emit — one display list; native and wasm renderers draw the same numbers.

Quick start#

$ cargo run -p quire-cli -- roundtrip corpus --check
✓ 399/399 byte-identical   ✓ 1 quarantined (upstream CRC corruption)
$ cargo run -p quire-cli -- render report.docx --out out/
→ out/report-p0.svg … p11  + pagebreaks.json
